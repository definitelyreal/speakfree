## What to test (focus areas)

### Must test (Wave 1 changes with user-visible surface area)

| Area | What to check |
|------|--------------|
| **large-v3-turbo default** | Fresh install should prompt to download large-v3-turbo (~1.5 GB). Transcription should be noticeably faster than large-v3. Check Settings shows it as the model. |
| **Streaming preview** | Hold key and speak. Overlay should show live text. No `[BLANK_AUDIO]` or `(silence)` should appear in the overlay. |
| **Secure Input guard** | Open a password field (System Preferences password prompt, or iTerm in secure mode). Hold key, dictate. App should silently skip insertion — no text typed into the password field. |
| **Remote desktop (if applicable)** | If you use Splashtop/TeamViewer: hold key, dictate multi-line. Should paste cleanly via clipboard. Single-line should type via AppleScript. |
| **Anti-hallucination** | Record ~0.5s of silence or near-silence. Old build would sometimes return "Thank you." or "[BLANK_AUDIO]". New build should return empty. |
| **Latency log** | Check diagnostic log (`~/.config/speakfree/speakfree.log`). Latency should read ~0.3s higher than before (was undercounting the post-buffer delay). |

### Regression watchlist (things that could have been broken)

- Normal dictation still works (hold key → speak → release → text appears)
- Toggle mode still works if configured
- Settings UI still opens, model picker shows large-v3-turbo
- Crash recovery still works (kill -9 while recording, relaunch → "found recording" prompt)
