# speakfree 2.0 — design

**Status:** approved 2026-05-23. Brainstorm history + research/scout artifacts in [`build/26-05-17-tune-corpus/`](../../build/26-05-17-tune-corpus/) (GLOSSARY-DESIGN, BRAINSTORM-SYNTHESIS, SCOUT-FINDINGS, ISSUE-TAXONOMY, RESEARCH).

## Goal

Move speakfree from "works but degrades over time and breaks in specific apps" to "reliably accurate dictation everywhere, doesn't degrade." Specifically: fix the gradual quality decay Michael experienced; eliminate the Signal-class app-specific lag; resolve crash-class concurrency bugs the scouts found; replace the brittle wrong→right autocorrect with a privacy-safe glossary; make the whole pipeline testable end-to-end.

v1.2.11 hotfix already shipped (Sparkle, prompt-feedback, regex fixes, pruning, turbo option). 2.0 is everything else.

## Scope — four tracks

### Track A — Glossary v2
Replace the polluted, drift-prone wrong→right correction map with a **bias-only** glossary system. Full design in [GLOSSARY-DESIGN.md](../../build/26-05-17-tune-corpus/GLOSSARY-DESIGN.md). Locked decisions:
- **Mechanism:** entries only **bias** Whisper's prompt-prior, never **substitute** post-hoc (no global phonetic-snap — structurally eliminates the Thomas/Tomass cross-context bleed).
- **Sources, all bias-only:**
  - **Explicit import** (extends existing `vocabulary.txt`, surfaced in Settings).
  - **Contacts** via `CNContactStore` — one-time *reviewed* import, names only, tagged `# contacts`.
  - **Ephemeral visible-conversation read** — walk AX tree from focused field up to window; capitalization+frequency extract; feed prompt + scoped candidate set; discard after each dictation. **Provenance-gated** (never learn from app's own un-edited insertions — uses `lastTranscription`).
- **Consent:** **inherit existing `screenContext` permissiveness** as the default for the new visible-conversation read (don't auto-expand past prior consent). Migration dialog discloses + shows current setting.
- **Persistent store:** encrypted at rest via a random Keychain key (`kSecAttrAccessibleAfterFirstUnlock`) — transparent, no Touch ID, loss-tolerant (regenerable from Contacts re-import).
- **Privacy guards:** never read secure fields (`AXSecureTextField`); high-entropy/secret token exclusion; per-entry forgettable + "forget all auto" + nuke; backup-exclusion xattr.
- **Migration dialog:** extends existing `VocabularyMigration` sentinel pattern. Cleans polluted `# auto` entries; offers (not forces) turbo download; shows current settings; never auto-expands permissions.
- **Retire `dictionary.json`** entirely.
- **Deferred to a later release:** the suggest-then-confirm "Remember 'Bexx'?" review queue + session-only lexicon (layer 4 from the design); the cascade reasoner (layer 5).

### Track B — Insertion re-architecture
Replace the hardcoded bundle-ID detection with **runtime classification + clipboard-safety check + universal AX time-bounding**. Fixes Signal lag *and* every undetected app. Full design + research in [BRAINSTORM-SYNTHESIS.md](../../build/26-05-17-tune-corpus/BRAINSTORM-SYNTHESIS.md). Locked decisions:
- **Runtime classifier** (ordered, no per-app DB, cached per-pid, sub-ms):
  1. `IsSecureEventInputEnabled()` → **manual-paste affordance** (terminals/password fields silently block all synthetic injection).
  2. Frontmost app bundle has `Contents/Frameworks/Electron Framework.framework` **or** `Chromium Embedded Framework.framework` → **Chromium** (catches Electron forks AND CEF apps like Spotify/Steam).
  3. `Info.plist LSRequiresIPhoneOS` → **Catalyst**.
  4. AX focused-element shape: `kAXWebArea` → web-view, opaque/no-text → canvas, native `AXTextField` → native. *Bundle-probe MUST run first — Chromium's lazy AX tree returns empty until probed.*
  5. Remote-desktop (existing bundle-ID list) → AppleScript keystroke (keep this — it's a "pixels-not-AX" class, not a UI-framework class).
- **Strategy per class:**
  - Native / Catalyst → AX-set with timeout (instant, non-destructive).
  - Chromium → **clipboard paste, safety-checked + transient-marked** (also retires the Superhuman special-case automatically).
  - Web-view / canvas → CGEvent keystrokes.
- **Clipboard-safety check (resolves the 5GB photo concern):** before pasting, inspect `NSPasteboard` — if it holds large-bytes or promised data, **DO NOT clobber it**; fall to CGEvent keystrokes instead. Full-fidelity restore is provably infeasible (research in [BRAINSTORM-SYNTHESIS.md]) so we *avoid* the destructive path entirely for precious clipboards.
- **Transient marking:** mark all speakfree clipboard writes with `org.nspasteboard.TransientType` + `ConcealedType` so Maccy/Raycast/Paste skip recording dictated text.
- **Universal AX time-bounding:** `insertViaAccessibility` currently has no timeout (the Signal-jank root cause). Every AX op gets a hard timeout + background queue.
- **Per-app override directory:** tiny crowd-grown overrides only, NOT a giant DB. The catalog idea is rejected — runtime classification handles forks; App Store data confirmed useless (most Electron apps ship outside MAS).
- **Deferred:** any Homebrew-Cask-analytics seed scan (not needed; runtime detection covers it).

### Track C — Hardening (scout's ship-blockers)
Crash-class + privacy-class fixes the scouts surfaced. Full inventory in [SCOUT-FINDINGS.md](../../build/26-05-17-tune-corpus/SCOUT-FINDINGS.md). Ship in 2.0:
- **#2 WhisperEngine use-after-free in streaming callback** — copy values before `DispatchQueue.main.async`, retain until callbacks drain.
- **#3 Whisper ctx freed during inference** — engine owns a serial queue/lock for load/transcribe/unload; memory-pressure unload coordinates with it.
- **#6 Config data race during transcription** — snapshot config on main at finalizeRecording entry.
- **#7 `isPressed` cross-thread** — confine mutation to main or atomic.
- **#8 Model integrity** — pin SHA-256 per model; verify on install.
- **#9 Stale OCR context bleeding into later transcription** — per-recording generation token.
- **#10 AX force-cast guards** (`rangeValue as! AXValue` w/o `CFGetTypeID` check at `AppDelegate:416`, `TextInserter:28`).
- **#11 Clipboard fallback leak** — fixed in Track B (transient marking + safety check).
- **#12 AppleScript escaping gaps** (newlines + processName).
- **#13 No-speech filter can drop whole transcription** — fall back to highest-prob segment.
- **#14 SIGINT bypasses cleanup** — flag + run-loop stop, not `exit()`.
- File perms: dir `0700` / files `0600`; `NSURLIsExcludedFromBackupKey` on recordings dir.

### Track D — Test pyramid
Make the pipeline testable end-to-end so future regressions get caught before users feel them. Locked decisions:
- **A. Shared text PipelineCore** — extract `prompt-assembly → process() → applyStyle()` into a pure `TextPipeline.process(raw:context:screenContext:mode:styleMode:vocabulary:) -> PipelineResult`. App and tests both call it. **The extraction IS the test** — today prompt-assembly is an inline closure (`AppDelegate.swift:580`), so a text test would test a reimplementation that drifts (exactly how the comma loop shipped).
- **B. Audio goldens via headless `speakfree process <wav>`** — new CLI subcommand emits JSON `{raw, processed, styled}`. Fixtures from preserved recordings. **Property assertions** (no comma-spam, no apostrophe-spaces, spoken-period preserved, no homophone cross-context bleed, contains-required-name), not exact-match. Pin model SHA per fixture suite; treat model bumps as deliberate "re-bless."
- **C. The riskiest untested code gets covered:** insertion (AppleScript escaping, clipboard-restore changeCount, classification per app class, secure-input path), threading (state-machine + config-reload + late-OCR races), Sparkle (appcast validation test that fails if signature isn't valid base64).
- **D. Build/release gate:** assert `sparkle:edSignature` is base64, ≥40 chars, never digits-only before any release script proceeds. (We have this in build.sh now; lock it with a test.)

## Release waves

Each wave is its own auto-update release, ships behind 2-3 days of Michael's dogfooding, with adversarial subagent review of the diff before publish.

| Wave | Version | Contents | Why this order |
|---|---|---|---|
| **1** | 1.3.0 | Track D (PipelineCore + `speakfree process` + golden harness) + Track C (Whisper crashes, AX guards, config snapshot, no-speech salvage, file perms) | Test infrastructure FIRST so everything after is testable. Crash fixes FIRST so features build on stable ground. |
| **2** | 1.4.0 | Track B (insertion re-architecture: classifier + clipboard-safety + Secure Input + transient marking + universal AX time-bounding) | Fixes Signal-class problems + the broad "undetected apps lag/silently fail" class. Independent of glossary. |
| **3** | 2.0 | Track A (glossary v2: bias-only, ephemeral, Contacts, encrypted store, migration dialog) + retire `dictionary.json` | The biggest user-visible change; lands last on a stable, well-tested base. |

## Verification disciplines (every wave)

1. **Test-first for new components** (PipelineCore, classifier, encrypted store, migration).
2. **Atomic commits** — one logical change per commit, `git bisect`-friendly.
3. **Adversarial subagent review** (Codex + Opus) on every wave's diff before publish — same pattern that caught the Sparkle and Whisper UAF bugs.
4. **End-to-end Sparkle update test** before each release (an old-version install must successfully update).
5. **Property-based audio fixture tests** must remain green; new regressions get codified as new fixtures.
6. **Manual dogfood** by Michael for 2-3 days per wave on the app shortlist.
