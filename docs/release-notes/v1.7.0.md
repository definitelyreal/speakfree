## speakfree v1.7.0

- **Custom names now come out right.** A curated name corrector plus an exact-override table make Parakeet (and Whisper) transcribe your people, places, and vocabulary correctly instead of garbling them.
- **No more dropped endings on Parakeet.** Fixed a decoder issue that silently truncated the last clause of a sentence.
- **Fixed an AirPods/Bluetooth crash.** The app no longer crashes when the audio device changes mid-use.
- **The recording overlay follows your active screen** — correct placement on multi-monitor setups.
- **Faster, more reliable model download** with real progress, no onboarding deadlock, and a self-healing model cache.
