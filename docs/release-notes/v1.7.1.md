## speakfree v1.7.1

- **Launch at login is on by default** for new installs (uncheck it in setup or Settings if you'd rather not).
- **Parakeet is now the top, default choice** in the setup dialog — the fast Neural Engine model, English by default.
- **Cleaner setup:** the language picker is hidden when you've chosen an English-only model, instead of showing a pointless one-item menu.
- **Fix:** the Help window now opens reliably.
- **Fix:** a denied microphone is surfaced clearly instead of silently recording nothing.
